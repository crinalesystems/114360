# 114360

A launcher and installer for running FINAL FANTASY XI on the Xbox 360, or in Xenia, against today's private servers.

## Download

Click **Releases** (on the right of this page) and select the latest one, marked **Latest**. Download the zip for
your system, Windows or Linux, unzip it, and read `README.txt` inside.

No game data is included.

## Credits

Run `114360-installer -credits` to see who made what and every license in full.
